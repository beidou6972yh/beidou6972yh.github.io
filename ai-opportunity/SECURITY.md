# 安全与数据处理

请勿在公开 Issue 披露真实数据或可利用的漏洞细节。报告时先提供不含敏感信息的概要，通过仓库所有者公开资料中的适当私下渠道协调详细内容。

当前设计：无账户、无后台文件持久化、无公共密钥。用户可主动保存数据到本机浏览器；此存储不是加密存储。密钥不持久化，第三方脚本依赖随站点固定版本托管。

模型请求只在用户确认后发往其指定的 HTTPS 服务（本机地址可用 HTTP），拒绝嵌入凭证的 URL，不自动跟随重定向，不携带站点 Cookie。响应有超时和大小上限。文档被视为不可信数据；HTML 转义和严格脚本来源限制用于降低注入风险。

限额不能替代企业级文件隔离、模型服务审查或企业数据政策。此版本用于小样本诊断。不要将模型建议直接用于设备控制、财务审批或审计定责。
