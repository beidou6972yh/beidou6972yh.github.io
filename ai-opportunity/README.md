# 家居 AI 机会诊断 · v0.2

**[在线使用 →](https://beidou6972yh.github.io/ai-opportunity/)** · [行业研究与官方来源](INDUSTRY_RESEARCH.md) · [实现与判断方法](DESIGN.md) · [示例材料](examples/order-review.csv)

从用户的真实岗位出发，通过引导式访谈、材料和透明测算，找出定制家居工作中值得试点的AI动作。手机与电脑直接打开使用，无需安装。

A Chinese-first guided interview for custom home furnishing professionals: role discovery, user-led AI ideas, local evidence, iterative clarification, transparent value estimates, and a user-approved one-screen action report.

## 这一版怎么用

1. 先说您在组织中的位置、岗位与职责。每次只回答一个重点。
2. 结合一笔实际业务，聊输入输出、流程方法、技能数据与绩效目标。
3. 说说您认为AI可以帮忙的地方、想要的表现形式和限制。
4. 上传或粘贴脱敏材料；没有材料时可以继续，但保留证据缺口。
5. 澄清关键问题，核对岗位画像，比较多个候选场景。
6. 逐个确认数据、规则、复核和试点条件，填写自己的价值假设。
7. 不满意就继续沟通、修改并重算。最终认可一个优先场景后，形成一屏行动报告。

报告包含场景目标、人机协作、价值与验收、必要条件、应用形式、技术路线。可下载Markdown、打印，或下载完整访谈JSON供留存；JSON导入和跨设备同步尚未实现。主界面“工具”中可体验虚构示例及保存/恢复本机访谈。

## 全链条范围

需求对接、营销锁客、设计方案、报价、审单、下单、拆单、排单、生产制造、质检检测、物流运送、上门安装、售后服务，以及贯穿全链条的行为审计、经济审计。页面只展开与岗位相关的初步候选，其他环节可按需选择。

## 行业基础

内置对GB/T 39016—2020、GB/T 3324—2024、GB 18584—2024、GB 28008—2024公开信息的研究，以及国家统计局家具制造业/家具零售数据快照。公开来源、日期、统计口径与应用边界可在页面或[行业研究](INDUSTRY_RESEARCH.md)查看。

行业知识转化为订单/版本追溯、需求与尺寸确认、工艺约束、质量交付及成本口径的追问。没有将宏观数据代填为用户收益，也没有把标准元数据当成完整合规检查规则。

## 两种方式

**本地引导，无需密钥。** 规则访谈、关键词场景匹配、材料相关性摘录、条件分级和收益计算均在浏览器运行。这不是云端大模型对话，也不声称自动理解任意文件或完成实际审单。用户可以修正画像、选择其他环节、自行修订场景动作与实施方案。

**可选AI辅助。** 点“连接AI深入追问”，填写兼容Chat Completions的HTTPS接口、模型ID与密钥。授权本轮回答和材料发送到该服务后，模型会逐轮分析并追问；也可在场景页请求综合分析。授权前可查看当前发送内容，随时断开。服务需支持CORS；未提供公共密钥或公共后端。模型接口流程使用模拟响应验证，实际服务需要用户自己的接口和额度。

模型原文引用必须在对应材料中匹配；匹配仅证明引文存在，不证明推断成立。模型不能自动确认条件、收益数字或报告可行性。

## 分级与价值

“超级适合且价值明显—A—B—C—D”分别表示条件及实测价值充分、适合先试点、有条件适合、当前暂不优先、当前方式不适合。每个场景显示原因和未解决的条件。完整门槛见[实现说明](DESIGN.md)。未知条件不会被当成0分或自动判D。

工时测算使用月任务量、覆盖率、原耗时和AI使用后总耗时（含准备、等待、处理、复核）。现金测算另外需要人工成本、可兑现比例、月费用和初期投入；空出的时间不等于工资减少。质量、风险和增收目标先作为验收指标，不自动货币化。各场景不自动汇总，避免重复计收益。

只有用户明确认可、四项试点条件确认具备、测算完成且等级不是C/D，才显示“用户已确认可行”。否则可导出讨论稿。后续修改将清除旧认可。

## 材料与隐私

支持TXT、Markdown、JSON、CSV/TSV、DOCX、XLSX、文字PDF。最多8份，每份8MB，最多保留40,000字符；模型单次材料摘录最多60,000字符。PDF仅文字层前40页，不做扫描OCR；Excel使用缓存值，不重新计算公式；不读取CAD。文件提取保留段落、行、工作表或页码线索。

默认只在当前页面内存中。主动“保存到本机”才写当前浏览器localStorage，包含回答和材料，非加密存储。密钥仅存页面内存，不写存储、报告或仓库。网页无遥测、无账户数据库；材料本地提取不上传GitHub。连接模型时，授权内容才发往指定服务。

v0.2使用独立本机保存键，不自动迁移v0.1数据。清空访谈会删除本机两版保存。请在刷新前保存或下载，分享报告前检查内容。

## 开发与部署

这是现有GitHub Pages仓库中的独立子目录，不依赖父级学术主页。依赖按固定版本随站点托管，不使用运行时外部CDN。

```bash
cd ai-opportunity
npm ci
npm test
node server.js
# http://127.0.0.1:8080/
```

Node.js 22+。`server.js`仅提供本机静态服务，不含模型代理。发布时更新本目录，GitHub Pages按父仓库已有流程部署。`core.js`保留v0.1兼容函数，新版页面使用`interview.js`的访谈和分级逻辑。

不提供真实ERP/MES写入、自动下单、设备控制、CAD几何处理、正式质检放行或审计定责。报告用于确定小范围试点，而非替代这些系统与责任流程。
