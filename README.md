## 家居 AI 机会诊断（开源工具）

**[在线使用 →](https://beidou6972yh.github.io/ai-opportunity/)** · [源码与使用说明](ai-opportunity/README.md) · [实现与评估方法](ai-opportunity/DESIGN.md)

覆盖需求对接到售后的 13 个业务环节，以及全链条行为审计和经济审计。v0.2采用从岗位出发的引导式访谈，结合行业依据、实际材料、多场景分级和价值测算，经用户反复沟通后生成一屏行动报告，手机可直接使用。本工具的 MIT 许可仅适用于 `ai-opportunity/` 子目录。
